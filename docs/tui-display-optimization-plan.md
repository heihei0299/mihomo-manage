# TUI 显示优化计划

> 制定日期：2026-10-18。状态：已实现，自动验证通过；真实终端人工验收未完成（见第 5 节）。

## 1. 目标与范围

统一现有 TUI 的页面布局，改善窄屏、长文本和内容溢出问题。保留英文文案、现有操作按键及业务行为，继续使用 Bubble Tea + Lipgloss，不重做导航、不增加服务管理功能。

验收尺寸：
- **标准布局：≥80×24**。
- **紧凑布局：≥60×16，但未达到标准布局尺寸**。
- **低于60×16：显示调整窗口提示**。

## 2. 页面与布局调整

- **统一页面框架**：在 `tui.go` 中增加内部页面描述与布局计算方法，统一为“顶部标题／可选标签栏 → 内容区 → 底部快捷键”。覆盖首页、配置、版本选择、定时设置、卸载确认，以及加载、错误和执行中状态。
- **动态分配空间**：先计算标题、标签栏、反馈及快捷键的实际高度，再确定正文预算；底部提示固定可见，正文不依赖终端自动换行或裁切。
- **首页信息层级**：标准布局保留紧凑双列状态卡；紧凑布局改为无边框单列。状态、版本、配置、自启动及定时信息保持原有含义，错误与操作结果使用独立提示区。
- **快捷键自适应**：以完整“按键＋说明”为单位按宽度排列，不再固定两行；保留不可用操作的弱化显示。使用现有语义配色，并保留文字或符号区分，不能只靠颜色表达状态。
- **正文超高处理**：普通信息页允许使用 `↑↓/j/k`、`PgUp/PgDn` 阅读溢出内容，仅在需要时显示滚动提示；版本及定时列表保留原选择语义，并确保选中项可见。页面切换或内容替换时重置阅读偏移，缩放时夹紧偏移。
- **特殊状态**：执行中继续显示 spinner、阶段与耗时，不新增取消行为；过长阶段消息在剩余空间内折行，仍超高时以省略标记收尾。小于最低尺寸时不接受新的业务操作，保留当前状态原有的退出／返回能力，后台进度继续处理。

## 3. 配置预览与内部接口

- **预览自动折行**：按终端显示单元计算宽度，保留 YAML 缩进、空行及完整文本，不修改原始配置内容；处理长 URL、路径、中文和组合字符，避免按字节截断。
- **统一滚动预算**：预览按折行后的屏幕行滚动，翻页步长等于实际正文高度；保留屏幕行与源文件行的映射，页脚继续显示当前源行范围。
- **缩放与刷新**：窗口宽度变化后重新折行，尽量保持顶部源行不变；刷新完成后回到顶部。错误、加载和空内容状态使用同一页面框架。
- **接口边界**：仅增加内部布局、折行及显示偏移状态；不改变 manager 接口、CLI 输出或配置格式。复用已锁定的 `x/ansi` 处理能力，必要时提升为直接依赖，不新增或升级模块。
- 尚未收到窗口尺寸事件时，以80×24作为初始渲染预算，首个尺寸事件到达后立即替换，避免误显示“小窗口”提示。

## 4. 验证与交付

在 `tui_test.go` 中补充表驱动测试：

- **尺寸约束**：覆盖120×40、80×24、60×16和低于最低尺寸的场景；逐行显示宽度不超过窗口，总高度不超过窗口，必要快捷键始终可见。
- **内容边界**：覆盖长版本号、长路径、多行错误、长配置行、Unicode、ANSI 样式及无颜色模式；确认无文本丢失、边框错位或原始配置修改。
- **交互回归**：覆盖折行后滚动与翻页、缩放定位、刷新重置、列表选中项可见，以及原有操作可用性、确认流程和页面返回行为。
- **人工验收**：通过模拟数据渲染全部页面，检查深浅背景、连续缩放、alt-screen退出恢复；更新 `docs/acceptance-tests.md` 的 AT-19，不为验收触发真实安装、卸载或服务变更。

计划制定阶段，现有相关测试基线已通过：

实施后运行受影响的显示层测试及根包测试，审查相关 diff；不默认运行全仓库测试，不改动工作区已有的无关文件。计划制定阶段尚未进行真实终端视觉验收。

- **A. 长错误完整可读、颜色不泄漏**：提示区固定一行摘要，完整错误（状态读取、服务操作、配置编辑、预览、版本查询）进入可滚动正文；滚动偏移由实际内容决定——只有正常预览正文使用 `previewOffset`，错误详情使用 `readOffset`；彩色文本一律先折行再逐行着色，裁切与滚动都不会丢失颜色重置。

- **C. 消除正文与页脚的循环计算**：源行范围独占一行并在计算预算时预留，正文窗口一次确定；快捷键最多计算两次（基础 + 滚动提示），渲染、滚动、翻页与缩放共用同一窗口结果。
- **D. 固定关键内容的空间优先级**：执行页先保留 spinner、操作名称与耗时，仅裁切阶段消息并以省略号收尾；版本页 `installed:` 单行省略，列表至少保留一行且选中标记始终可见；过小窗口先保留退出／返回提示，再排列尺寸说明，空间不足时优先省略标题。
